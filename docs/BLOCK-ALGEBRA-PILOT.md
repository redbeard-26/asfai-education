# Block Algebra pilot

The first bundled lesson is `urn:asfai:lesson:block-algebra-foundations` version `1.0.0`. It combines:

- a guided walkthrough for deliberate acquisition evidence;
- an assistant reasoning checkpoint;
- a Block Algebra Drop practice round;
- a qualifying Drop fluency round;
- symbolic transfer work; and
- a learner reflection and lesson-specific report.

The four lesson objectives are scoped ASFAI objectives because the current Marble graph does not contain exact equivalents for all four. The manifest records close or related Marble alignments where available. No Marble records are copied.

Walkthrough interpretation uses deliberate Check attempts, completion, and failure patterns. Drop interpretation uses only constructed, non-chain clears. The first Drop game is practice and cannot lower a judgement. Speed is secondary because it can reflect dexterity, stress, and board conditions.

All included bands are marked `calibrationStatus: pilot`. They can suggest emerging, developing, or proficient evidence but cannot automatically create mastery. Mastery requires evidence across multiple modalities, including independent evidence. Area-model game performance should be combined with learner explanation and symbolic transfer.

Known accessibility boundary: both imported games remain pointer-oriented. Each artifact manifest therefore declares keyboard support as unavailable and supplies an assistant-led untimed fallback. Keyboard-native game controls remain required before the games can be the sole path through a lesson.
